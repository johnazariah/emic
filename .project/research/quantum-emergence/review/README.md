# Quantum Emergence Literature Review

*Systematic review of quantum computational mechanics literature*

---

## Scope

This review covers the intersection of:
- **Computational mechanics** (Crutchfield, Shalizi)
- **Quantum information theory** (Gu, Vedral, Thompson)
- **Quantum simulation** of stochastic processes

## Key Themes

1. **Quantum memory advantage**: Quantum simulators require less memory than classical epsilon-machines
2. **Crypticity elimination**: The gap $C_\mu - E$ represents classical waste that quantum can eliminate
3. **Non-orthogonal encoding**: Quantum advantage comes from using non-orthogonal states for causal states with different pasts but identical futures
4. **Thermodynamic connections**: Links to work extraction and heat dissipation
