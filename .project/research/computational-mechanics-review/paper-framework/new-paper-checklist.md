# New Paper Checklist

Use this checklist whenever starting a new paper in this project.

## Metadata

- [ ] Use canonical author metadata from `shared/metadata/author-profile.yaml`
- [ ] Ensure name, affiliation, ORCID, and email match the canonical profile
- [ ] Set date and venue metadata for the target publication

## Disclosure

- [ ] Include an AI disclosure section or acknowledgment note
- [ ] Use the shared disclosure text from:
  - Markdown: `shared/snippets/ai-usage-disclosure.md`
  - LaTeX: `shared/snippets/ai-usage-disclosure.tex`
- [ ] Keep wording consistent unless venue policy requires changes

## References and style

- [ ] Use shared bibliography: `shared/bibliography/references.bib`
- [ ] Use citation keys in format `{first-author-name}{year}[{tag}]`
- [ ] Keep notation and terminology consistent with existing papers
